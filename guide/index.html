AnyCompany를 위한Quick Desktop 실습

Amazon Quick Desktop으로 업무를 자동화해 보는 실습입니다. 공통 실습 3개를 따라한 뒤, 각자 준비한 업무 아이디어를 직접 만들어 봅니다.

자유 실습내 업무 자동화
채팅 한 문장으로 시작별도 설치 없이 Quick Desktop에서 바로 실습

공통 실습 1

1

업계 뉴스 아침 브리핑

핵심: 매일 정해진 시간에 뉴스를 찾아 Activity Feed에 올려 주는 스케줄 만들기

아래 문구를 채팅창에 붙여넣으세요

PROMPT
매일 아침 9시에 어제 나온 AI·IT 업계 주요 뉴스 3개를 한 줄씩 요약하고 링크를 붙여 Activity Feed에 띄워줘.

실습 흐름

  1. 위 문구를 Quick Desktop 채팅창에 붙여넣기
  2. Quick이 만든 스케줄(시간, 할 일)을 확인하고 저장
  3. 바로 결과를 보려면 지금 한 번 실행해줘 입력
  4. Activity Feed에 올라온 뉴스 3개와 링크 확인

공통 실습 2

2

외식 프랜차이즈 광고 트렌드 PPT

핵심: 웹에서 찾은 업계 소식을 수정 가능한 차트가 들어간 PPT로 만들기

아래 문구를 채팅창에 붙여넣으세요

PROMPT
최근 한 달 외식 프랜차이즈(버거, 치킨, 커피, 피자)의 신규 프로모션, 광고 캠페인, 신메뉴 출시 소식을 웹에서 10건 이상 찾아서 광고 트렌드 PPT 만들어줘.
찾은 소식을 기준으로 프로모션 유형 비중, 업종별 소식 수, 광고 채널 비중, 소식이 많은 브랜드 상위 5곳을 차트로 만들어서 수정가능한 형태로 ppt에 넣어줘.
주요 사례 3개는 한 장씩 출처 링크와 함께 정리하고, 마지막 장에는 광고주에게 제안할 광고 포인트를 요약해줘. 한국어로 말해줘.

실습 흐름

  1. 위 문구를 Quick Desktop 채팅창에 붙여넣기
  2. Quick이 슬라이드 플랜 제시 → Approve 클릭
  3. 실시간으로 PPT가 만들어지는 과정 확인 (Session Tab에서 미리보기)
  4. 완성된 PPT를 열어 차트 4장과 사례 슬라이드 확인 (차트는 PowerPoint에서 바로 수정할 수 있습니다)

공통 실습 3

3

회의실 예약 MCP 연결

핵심: AWS에 만든 회의실 MCP 서버를 Quick Desktop에 연결해 채팅으로 회의실 예약하기

AgentCore Gateway → Lambda → DynamoDB · 도구: 회의실 목록, 예약 현황, 예약, 취소, 내 일정

1. 아래 MCP 설정 복사

meeting-room-mcp.json
{
  "mcpServers": {
    "meeting-room": {
      "type": "http",
      "url": "{{MCP_URL}}",
      "headers": { "Authorization": "Bearer {{ACCESS_TOKEN}}" }
    }
  }
}

토큰이 들어 있는 설정입니다. 24시간 동안 쓸 수 있습니다.

2. Quick Desktop에 붙여넣기

⚙️ Settings › Capabilities› + Create › MCP server› Connection type: Remote› Paste JSON에 붙여넣기› Add MCP

3. 채팅으로 써 보기

PROMPT A
오늘 오후 3시에 4층 대회의실 1시간 예약해줘. 예약자는 내 이름, 제목은 주간 회의로 해줘
PROMPT B
내일 오전에 8명이 쓸 수 있고 화상회의 되는 회의실 중 비어 있는 곳 알려줘
회의실 현황 화면 열기 ↗ 예약하면 해당 회의실이 바로 "사용 중"으로 바뀌는 것을 볼 수 있습니다
